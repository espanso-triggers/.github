# Espanso - Snippets You Choose to Expand

![Espanso with one match the user wrote for their own text](https://ileif.de/wp-content/uploads/2023/11/Konfiguration-im-pico-Editor-1024x785.png)

## Product Snapshot

Espanso watches for triggers you configured and replaces them with snippets you stored. The point is a date, an address, or a paragraph you type often. The configuration is a file you can read. If you cannot explain a match, do not enable it.

It runs in your Windows session. It does not belong on a PC you are using to capture someone else's typing, and it should not expand secrets into a chat by accident. A trigger that is too short will fire while you write ordinary words. Pick a trigger you will not type by mistake.

## Mount and Burn Toolkit

| Task | What you get |
|---|---|
| Match | A trigger and the text that replaces it |
| Toggle | A way to stop expansion |
| Snippets | Paragraphs you wrote |
| Packages | Extra matches, only after you read them |
| Config | A file you can copy and restore |
| Date | A built-in expansion you can test safely |

Test in Notepad, not in a message you are about to send. A wrong expansion in a chat is still a send once you confirm it.

## Deep Dive

Add one match, such as a short trigger that becomes your name or a sentence you use. Type it in a blank note. If the sentence appears, the match works. If it appears when you did not mean it, lengthen the trigger. Copy the config before you install a package. A package can add many matches at once, including ones you would not want in a password field.

Disable Espanso before you enter passwords, banking pages, or a one-time code. Enable it again for ordinary writing. On a shared PC, quit it when you leave. The config can contain private addresses. Do not put that file in a public folder.

## Adoption Paths

Espanso fits repeated text you are tired of typing, on a PC you control. It fits a date stamp or a polite sign-off you wrote. It does not fit recording another person, a shared kiosk, or a package of snippets you have not read.

## Install Walkthrough

Prerequisites: This Windows user is yours, and you accept that a trigger can expand in any text box while Espanso is on.

1. Install Espanso and leave it off until you add one match.
2. Write a trigger you will not type by accident, and a harmless sentence.
3. Toggle it on and try the trigger in Notepad.
4. Turn it off and confirm the trigger stays as plain text.
5. Read any package before you enable it. Keep a copy of the config.
